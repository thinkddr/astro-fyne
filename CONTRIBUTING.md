# Contributing

Pull requests are welcome from anyone.

- Open an issue first for larger changes so the approach can be discussed.
- Keep each pull request focused, with tests where applicable.
- Never include secrets, credentials, tokens or real environment values.
- By submitting a contribution you agree it is licensed under this repository's license.

**Maintainer:** [@thinkddr](https://github.com/thinkddr) (Daniel Delgado Ramos) is the only
maintainer. Every pull request requires his review and approval, and only he can merge.
Security issues: please use GitHub's *Private vulnerability reporting*, not public issues.
